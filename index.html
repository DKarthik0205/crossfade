Where do I get a Client ID?
Crossfade runs entirely in your browser, so it needs its own Spotify app registration — free and takes about a minute.
  1. Open the Spotify Developer Dashboard and log in.
  2. Click Create app. Name it anything, e.g. "Crossfade".
  3. For Redirect URI, paste exactly this page's URL:
  4. Enable the Web API checkbox, save, then open the app's Settings and copy the Client ID into the field above.

Connect Apple Music
Apple Music requires a developer token (a signed key from an Apple Developer account) — Crossfade can't generate this for you, but it only takes a few minutes if you don't already have one.
Where do I get a developer token?
This requires an active Apple Developer Program membership ($99/yr) — there's no free tier for Apple Music API access.
  1. In your Apple Developer account, create a MusicKit identifier.
  2. Under Keys, create a new key with the MusicKit service enabled, and download the .p8 private key file.
  3. Sign a JWT with that key (ES256), using your Team ID as issuer and the Key ID as the key id — Apple's developer token guide has copy-pasteable examples in several languages.
  4. Paste the resulting token above. It's safe to keep reusing the same token until it expires (up to 6 months).
